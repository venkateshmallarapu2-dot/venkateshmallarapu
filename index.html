Stock Market Prediction

03

Handwritten Character Recognition

Designed and trained a deep Convolutional Neural Network on the EMNIST Balanced dataset comprising 814,255 labelled images across 62 character classes (digits 0–9, uppercase A–Z, lowercase a–z). The CNN architecture consists of multiple Conv2D layers with ReLU activations, MaxPooling for spatial downsampling, Batch Normalisation for training stability, Dropout (0.4) for regularisation, and Dense layers with Softmax output. Data augmentation — rotation, zoom, and width/height shifts — was applied via Keras ImageDataGenerator to improve generalisation. The model achieves ~92% top-1 accuracy on the test split with sub-100ms inference latency. OpenCV preprocesses the canvas input by applying grayscale conversion, Gaussian blur, adaptive thresholding, and contour-based bounding-box extraction before feeding into the model. The backend Flask API receives base64-encoded canvas frames, runs inference, and returns the predicted character and confidence score to the HTML5 Canvas frontend in real time.

Floods & Landslides Prediction

Engineered a geospatial disaster risk prediction system using a Support Vector Machine with an RBF kernel, trained on 20,000 environmental records spanning four critical features: rainfall (mm), river water level (m), soil moisture (%), and terrain slope (degrees). Data preprocessing includes MinMaxScaler normalisation, SMOTE oversampling to handle class imbalance between risk levels (Low / Medium / High), and cross-validated C and gamma hyperparameter tuning via GridSearchCV. The full-stack application is structured with Jinja2 templating, Bootstrap grid layout, and RESTful route separation for modularity.

Credit Card Fraud Detection

Developed a real-time financial fraud classification system addressing the highly imbalanced nature of fraud datasets — where fraudulent transactions represent less than 0.2% of records. The pipeline applies StandardScaler to normalise the PCA-transformed features (V1–V28) and SMOTE (Synthetic Minority Oversampling Technique) to synthetically balance the training distribution before model fitting. A Random Forest Classifier with 200 estimators was selected after benchmarking Logistic Regression, XGBoost, and Isolation Forest, achieving high Precision, Recall, and F1-Score on the minority fraud class — metrics deliberately prioritised over raw accuracy to minimise false negatives. The Pickle-serialised model is served via a Flask REST API that processes incoming transaction JSON payloads, runs synchronous inference, and returns a fraud/legit label with confidence score. The JavaScript frontend renders live transaction results with colour-coded alerts and a running fraud rate counter, simulating a real-time fraud monitoring dashboard.
